# Lab 0 — Java Syntax Basics

Foundational Java syntax before OOP: Hello World, variables, operators, input/output, conditionals, loops, arrays, and methods.

**Folder:** `Lab_0/`  
**Programs:** 10

---

## Program 1: Hello World

**Path:** `Lab_0/Program1_HelloWorld.java`  
**Concept:** Hello World & main method

The simplest Java program. Prints two lines to the console using `System.out.println()`.

```bash
cd Lab_0
javac Program1_HelloWorld.java
java Program1_HelloWorld
```

**Output:**
```
Hello, World!
Welcome to Java Programming
```
